# 🚀 SEO Toolbox & Research

Этот репозиторий посвящен инструментам и методам поисковой оптимизации (SEO). Здесь я собираю полезные скрипты, чек-листы и результаты анализа веб-проектов.

### 📋 Что внутри:
- **Аналитика:** Методы сбора ключевых слов и анализа конкурентов.
- **Техническое SEO:** Проверка скорости загрузки, структуры заголовков и мета-тегов.
- **Автоматизация:** (В разработке) Скрипты на Python для парсинга данных.
